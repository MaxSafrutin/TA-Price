# Генератор ценников ТИТАН АВТО

Статический офлайн-генератор ценников формата A4. Сервер и установка не нужны.

## Запуск

Откройте `index.html` двойным кликом в Chrome, Edge или другом современном браузере.

## Печать

1. Нажмите «Печать / PDF».
2. Формат бумаги: A4, книжная ориентация.
3. Масштаб: 100% или «Фактический размер».
4. Поля: нет.
5. Включите «Печатать фоновые изображения/графику».

Данные и изменённый список менеджеров сохраняются в браузере автоматически.

## Сохранённые ценники

Во вкладке «Сохранённые» можно открыть ценник для изменения, обновить его, создать копию или удалить.

- Рабочая база хранится локально в браузере и не отправляется в интернет.
- Кнопка «Экспорт JSON» создаёт файл `price-tags.json` для резервной копии в корне проекта.
- Кнопка «Импорт JSON» возвращает ценники из этого файла.
- При запуске через GitHub Pages или локальный веб-сервер приложение может загрузить записи из корневого `price-tags.json`, если локальная база ещё пустая.

## GitHub Pages

Загрузите содержимое папки в репозиторий и включите Pages для основной ветки. Все пути относительные, поэтому дополнительных настроек не требуется.

Ценники PDF и файл `price-tags.json` хранятся только локально и исключены из Git через `.gitignore`. Для публикации загружайте только файлы приложения, шрифты, используемый логотип и иконки. Для переноса локальной базы используйте «Экспорт JSON» и «Импорт JSON».

## Контакты менеджеров

В разделе «Настроить контакты» можно добавлять 20 и более менеджеров, менять имена и телефоны, удалять записи. Изменения применяются кнопкой «Сохранить»; «Отмена» их не применяет. Общий список сохраняется в этом браузере и используется при создании и открытии ценников. Это работает при локальном запуске и на GitHub Pages. Между браузерами и устройствами контакты автоматически не синхронизируются.
